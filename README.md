# Emioluwa Writes

A bespoke editorial journal and personal writing sanctuary for **Emioluwa**. Crafted with deliberate typography, thoughtful negative space, and modern web engineering.

## Features

- **Editorial Reading Experience**: Responsive layout with customizable typography, dark mode, reading progress indicator, estimated read time, and audio narration.
- **Categorized Archives**: Essays grouped across Student Life, Personal Growth, Self-Discovery, Life Experiences, Opinions, and Creative Writing.
- **Interactive Reader Engagement**: Real-time claps, threaded reader reflections & comments, bookmarking, and native share drawer.
- **Admin Dashboard**:
  - Secure login and administration.
  - Markdown piece editor with live preview, featured tags, and scheduling.
  - Category manager with inline edit and permanent delete safeguards.
  - Reader reflection moderation and contact inquiries management.
- **Full-Stack & Cloud Synchronization**: Supabase integration with fallback persistent local state, RESTful Express backend, and live synchronization.

## Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Backend**: Node.js, Express, Vite middleware
- **Database**: Supabase / Firestore compatible persistence

## Getting Started

### Prerequisites

- Node.js 18+
- npm or bun

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Build & Production

```bash
# Build production bundle
npm run build

# Start production server
npm start
```
